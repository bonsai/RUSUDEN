# RUSUDEN

留守電とダイヤルQ2 / P2の体験を、電話の段階として再構成するPOC。

## 現在の仕様

**電話盤は全員に見える公開UI。** `?debug=1` はデバッグ情報を追加表示するだけで、電話盤を隠さない。

```text
アプリを開く
  ↓
新しい録音が3件
  ↓
1 / 2 / 3 でQを選ぶ
  ↓
Qを聴く
  ↓
「この録音に返信しますか？」
  ├─ # → Aを録音
  │        ↓
  │      答えだけ吹き込む
  │        ↓
  │      保存 → 次のQ
  ├─ * → 次のQ
  └─ 0 → Qを再生
```

### 操作盤

```text
1 2 3
4 5 6
7 8 9
* 0 #
```

- `1–3` — Qを選ぶ
- `#` — この録音に返信する
- `0` — Qを再生する
- `*` — 戻る / 返信しない

マウス・タッチとキーボードの数字キーの両方に対応する。

### Q / A

- **Q** は届いた問い。クイズ、悩み、相談などを含む。
- **A** はQへの答えだけを吹き込む。
- Aの録音中にアプリが新しい質問を挟まない。

## デバッグ

`?debug=1` を付けると、通常の電話盤に加えて stage / voice state / event などの診断情報を表示する。

## POCとMVP

**POC** は「この電話体験が技術的・体験的に成立するか」を確認するもの。
固定された着信、ブラウザ音声、簡易的な返答でよい。

**MVP** は「実際に毎日使える留守電 / P2」として、着信生成、Mastra、音声入力、記録、継続利用まで成立させる。
