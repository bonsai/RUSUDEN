# RUSUDEN

留守電とダイヤルQ2 / P2の体験を、電話の段階として再構成するPOC。

## POCの到達点

```text
アプリを開く
  ↓
着信がいくつか届いている
  ↓
どれかを選ぶ
  ↓
電話に出る
  ↓
相手の声を聴く
  ↓
自分も話す / 質問する
  ↓
相手が返す
  ↓
電話を切る
```

### 留守電
「届いている声を聴く」

### Dial Q2 / P2
「届いた電話に答える」

### 次の段階
「自分から電話をかける / 質問を投げる」

このPOCでは、最後の一歩までをひとつの体験として成立させる。

## POCとMVP

**POC** は「この電話体験が技術的・体験的に成立するか」を確認するもの。
固定された着信、ブラウザ音声、簡易的な返答でよい。

**MVP** は「実際に毎日使える留守電 / P2」として、着信生成、Mastra、音声会話、記録、継続利用まで成立させる。

## Version

- `v0.1` — 着信一覧 → ひとつ選ぶ → 出る → 質問する → 返答 → 切る
- `v0.2` — 実音声入力 / 出力の安定化
- `v0.3` — Mastra接続
- `v0.4` — 着信を生成する
- `v0.5` — 留守電として保存する
- `v1.0` — MVP
